## Execution Timeline (Milliseconds)

```mermaid
timeline
    title Startup execution — from main.ts to traffic

    section Bootstrap
        0ms : main.ts → NestFactory.create(AppModule)
        1ms : Phase 1 — build module tree : register AppModule, EnvModule(@G), SubAppOrchModule, DatabaseModule(@G), AuthModule.forRootAsync, 20+ feature modules
        2ms : Phase 2 — resolve providers

    section Sub-app chain (BootstrapGate fires first — no deps → runs before all factories)
        3ms : BootstrapGate provider fires : SubAppOrchestrator.runAll(ALL_SUB_APPS)
        5ms : SubApp 1 ConfigSubApp (timeout 5s) : validate env vars NODE_ENV, API_PORT, DATABASE_URL : emit(config) + complete() : app.close() → destroyed
        9ms : SubApp 2 SetupWizardSubApp (timeout 5min) : checkConfigAndEmit() → no config : EphemeralHttpServer.start(0) → port 54321 : WAIT for user — GET /setup/state, POST /setup/initialize, SSE /setup/stream
        13s : user completes setup via browser : emit(databaseUrl, strategy) + complete() : EphemeralHttpServer.stop() : app.close() → destroyed

    section Remaining sub-apps
        14s : SubApp 3 DatabaseSubApp (timeout 60s) : await setupWizardTrigger.waitFor() → returns immediately : new Pool(databaseUrl) : drizzle(pool, schema) : emit(pool, drizzle, isMigrated) + complete() : app.close() → destroyed
        17s : SubApp 4 AuthSubApp (timeout 30s) : verify AuthCoreService.instance : emit(authInstance, ...) + complete() : app.close() → destroyed
        19s : SubApp 5 MeshSubApp (timeout 30s) : read meshUrlsSnapshot from config : connect to mesh peers : emit(meshClient, nodeId) + complete() : app.close() → destroyed
        23s : SubApp 6 EventsSubApp (timeout 10s) : verify event infrastructure : emit(eventBus) + complete() : app.close() → destroyed
        23s : SubApp 7 DockerSubApp (timeout 10s) : new DockerService(envService) : verify socket availability : emit(dockerode, socketAvailable) + complete() : app.close() → destroyed

    section Module resolution
        26s : BootstrapGate resolves — all sub-apps done
        27s : GlobalModule awaits databaseTrigger → returns immediately : provides GLOBAL_DATABASE_POOL, GLOBAL_DATABASE_CONNECTION, GlobalDatabaseService : CoreDockerModule awaits dockerTrigger → provides DockerService
        28s : AuthModule.forRootAsync receives DrizzleClient → creates BetterAuth : ORPCModule.forRootAsync receives AuthCoreService → binds router : all feature modules receive all deps → resolved

    section Lifecycle + listen
        29s : Phase 3 lifecycle hooks (onModuleInit, onApplicationBootstrap) : @Global() hooks first, then leaf modules, then AppModule
        30s : app.listen(3005) → 🚀 Server accepting traffic
```

## Key Design Points

| Aspect | Mechanism | Why |
|--------|-----------|-----|
| **Orchestrator** | `BOOTSTRAP_GATE` provider (Phase 2) | Runs before all module factories because it has no `inject` deps |
| **Sub-app ordering** | Topological sort of `dependsOn` fields | `config → setupWizard → database → auth → mesh → docker` |
| **Setup wizard** | Embedded in sub-app chain | Only runs on first boot; skipped via fast path if config exists |
| **Trigger sync** | `emit()` + `complete()` in sub-app, `waitFor()` in module factory | Singleton trigger services bridge sub-app output to main-app DI |
| **Module barrier** | Each module factory `await`s its trigger | NestJS provider barrier ensures ordering |
| **Clean teardown** | `app.close()` on each sub-app | `OnModuleDestroy` on all providers, connections closed, GC freed |

## Key Files Involved

| Step | File(s) | Role |
|------|---------|------|
| Entry point | `main.ts` | Creates NestJS app, enables shutdown hooks, configures CORS, listens |
| Module tree | `app.module.ts` | Root module — defines all imports, BOOTSTRAP_GATE provider |
| Foundation | `EnvModule`, `TriggersModule` (past) | `@Global()` modules — EnvService |
| Orchestrator | `SubAppOrchestrator.service.ts` | `runAll()` with topological sort |
| Sub-app runner | `SubAppContextModule`, `sub-app.interface.ts` | Provides SUB_APP_CONTEXT token |
| Config | `sub-apps/config/config.sub-app*.ts` | Validates env vars |
| Setup wizard | `sub-apps/setup-wizard/setup-wizard.sub-app*.ts` | HTTP wizard for first-time setup |
| Database | `sub-apps/database/database.sub-app*.ts` | Creates Pool + Drizzle |
| Auth | `sub-apps/auth/auth.sub-app*.ts` | Verifies BetterAuth |
| Mesh | `sub-apps/mesh/mesh.sub-app*.ts` | Connects to mesh peers |
| Events | `sub-apps/events/events.sub-app*.ts` | Verifies event bus |
| Docker | `sub-apps/docker/docker.sub-app*.ts` | Validates Docker socket |
| Trigger base | `core/modules/triggers/base-trigger.service.ts` | Extends BaseEventService |
| Per-domain triggers | `config.trigger.service.ts` etc. | 7 services with Zod schemas |
| DB provider | `core/modules/database/global/global.module.ts` | Awaits `databaseTrigger.waitFor()` |
| Docker provider | `core/modules/docker/docker.module.ts` | Awaits `dockerTrigger.waitFor()` |
| Registry | `sub-apps/registry.ts` | `ALL_SUB_APPS` list |
