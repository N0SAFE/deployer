## What this page gives you

Concrete payloads for the two event systems:

- **Business endpoints** under `/deployments`
- **Core sync endpoints** under `/core/events`

Examples are aligned with the current contracts in:

- `packages/contracts/api/modules/deployment/stream.ts`
- `packages/contracts/api/modules/events/index.ts`

## 1) Create a deployment stream definition (business layer)

Endpoint: `POST /deployments` stream-create contract route (deployment stream definition create)

Request body example:

```json
{
  "name": "prod-service-stream",
  "description": "Live deployment stream for production service",
  "isActive": true,
  "serviceId": "11111111-1111-1111-1111-111111111111",
  "statusFilter": "deploying",
  "environmentFilter": "production",
  "eventTypes": ["statusChanged", "phaseUpdated", "logAppended"],
  "replayDefault": true,
  "replayLimitDefault": 100
}
```

Typical response body (resource):

```json
{
  "id": "2f2f2f2f-2f2f-2f2f-2f2f-2f2f2f2f2f2f",
  "coreStreamId": "3a3a3a3a-3a3a-3a3a-3a3a-3a3a3a3a3a3a",
  "name": "prod-service-stream",
  "description": "Live deployment stream for production service",
  "isActive": true,
  "deploymentId": null,
  "serviceId": "11111111-1111-1111-1111-111111111111",
  "projectId": null,
  "statusFilter": "deploying",
  "environmentFilter": "production",
  "eventTypes": ["statusChanged", "phaseUpdated", "logAppended"],
  "replayDefault": true,
  "replayLimitDefault": 100,
  "createdBy": "user_123",
  "createdAt": "2026-02-23T16:00:00.000Z",
  "updatedAt": "2026-02-23T16:00:00.000Z"
}
```

Notes:

- `coreStreamId` is automatically created and linked.
- Scope is inferred from IDs: `deploymentId` → `serviceId` → `projectId` → global.

## 2) List stream definitions with typed filters

### 2.1 Deployment stream definitions

Endpoint: deployment stream list contract (`streamsList`)

Typical query shape (conceptual):

```json
{
  "filter": {
    "_and": [
      { "isActive": { "eq": true } },
      { "name": { "ilike": "prod%" } },
      { "environmentFilter": { "eq": "production" } }
    ]
  },
  "sortBy": "createdAt",
  "sortDirection": "desc",
  "limit": 20,
  "offset": 0
}
```

Response shape:

```json
{
  "data": [
    {
      "id": "2f2f2f2f-2f2f-2f2f-2f2f-2f2f2f2f2f2f",
      "coreStreamId": "3a3a3a3a-3a3a-3a3a-3a3a-3a3a3a3a3a3a",
      "name": "prod-service-stream",
      "isActive": true,
      "deploymentId": null,
      "serviceId": "11111111-1111-1111-1111-111111111111",
      "projectId": null,
      "statusFilter": "deploying",
      "environmentFilter": "production",
      "eventTypes": ["statusChanged", "phaseUpdated", "logAppended"],
      "replayDefault": true,
      "replayLimitDefault": 100,
```

### 2.2 Core stream definitions

Endpoint: `/core/events` list contract (`listStreams`)

Typical query shape:

```json
{
  "filter": {
    "namespace": { "eq": "deployment" },
    "scope": { "eq": "service" },
    "isActive": { "eq": true }

  "sortBy": "updatedAt",

  "limit": 20,
```

## 3) Update and delete stream definitions

### 3.1 Update deployment stream definition

Request body example:

```json
{
  "id": "2f2f2f2f-2f2f-2f2f-2f2f-2f2f2f2f2f2f",
  "isActive": false,
  "eventTypes": ["statusChanged", "deploymentCancelled"],
  "replayLimitDefault": 50
}
```

Behavior:

- updates deployment stream definition,
- updates linked core stream definition automatically (if `coreStreamId` exists).

### 3.2 Delete deployment stream definition

Behavior:

- deletes deployment stream definition,
- deletes linked core stream definition automatically (if linked).

### 4.2 Core sync stream (`/core/events/sync/{id}/stream`)

Query parameters:

- `replay=true`
- `replayLimit=20`

Sample envelope event:

```json
{
  "streamId": "3a3a3a3a-3a3a-3a3a-3a3a-3a3a3a3a3a3a",
  "namespace": "deployment",
  "eventName": "statusChanged",
  "payload": {
    "type": "statusChanged",
    "deploymentId": "d1d1d1d1-d1d1-d1d1-d1d1-d1d1d1d1d1d1",
    "serviceId": "11111111-1111-1111-1111-111111111111",
    "status": "deploying",
    "sequence": 4,
    "replayed": false,
    "emittedAt": "2026-02-23T16:01:05.000Z"
  },
  "sequence": 12,
  "replayed": false,
  "emittedAt": "2026-02-23T16:01:05.000Z"
}
```

Interpretation:

- outer `sequence` is for the core sync stream,
- inner payload may also contain namespace-specific sequence metadata.

## 5) Minimal mental model for developers

1. Create or update **deployment stream definition**.
2. System mirrors it to a **core stream definition** automatically.
3. Read business stream endpoints for feature-specific payloads.
4. Read core sync endpoint for normalized, namespace-agnostic envelopes.
