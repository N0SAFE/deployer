🎯 Core Concepts

Observable-First Design

  • All operations are fundamentally streams
  • SSE (Server-Sent Events) as transport
  • RxJS Observables for reactive API
  • Promises as convenience for one-shot

Resource Ownership

  • Global COORDINATED
  • Node-Owned SINGLE
  • Sharded PARTITIONED
  • Replicated HA

Event Sources

  • Mutation Events (CRUD operations)
  • External Events (webhooks)
  • Timer Events (scheduled jobs)
  • Stream Events (logs, metrics)
  • Replication Events (sync)

🏗️ Resource Ownership Patterns

Pattern Description Examples Query Strategy Listen Strategy
Global GLOBAL Single source of truth, coordinated by central node Projects, Organizations, Users Query global coordinator Subscribe to global event stream
Node-Owned NODE Owned by exactly one node Deployments, Logs, Local configs Query owner node directly SSE stream to owner node
Sharded SHARD Partitioned across multiple nodes by key Time-series data, Large datasets Route to shard holder Fan-out SSE to all shard holders
Replicated REPLICA Same data on multiple nodes for HA Critical configs, Session data Query any replica Subscribe to primary replica

💻 API Usage Patterns

One-Time Request (Promise-based)

const result = await discovery .from(resources.deployments) .where({ environment: "prod", status: "running" }) .orderBy("createdAt", "desc") .limit(100) .request(); // Returns Promise<QueryResult> for (const deployment of result.items) { console.log(deployment.deploymentId); }

Real-Time Updates (Observable-based)

const subscription = discovery .from(resources.deployments) .where({ serviceId: "my-service" }) .listen() // Returns Observable<ChangeEvent> .subscribe(event => { switch (event.type) { case "created": console.log("New deployment:", event.item); break; case "updated": console.log("Updated:", event.item); console.log("Changed fields:", event.changedFields); break; case "deleted": console.log("Removed:", event.item); break; } }); // Cleanup when done subscription.unsubscribe();

Fluent Builder API

const builder = discovery .from(resources.deployments) .where({ environment: "prod" }) .andWhere({ status: "running" }) .select(["deploymentId", "status", "version"]) .orderBy("createdAt", "desc") .limit(50) .offset(0); // Use for one-time request const result = await builder.request(); // Or for real-time updates const stream$ = builder.listen();

Type-Safe Resource Definition

const deployments = defineResource() .key("deployments") .itemSchema(deploymentSchema) .itemKey("deploymentId") .nodeOwnedOwnership("nodeId") .addQuery("list", { inputSchema: listInputSchema, outputSchema: listOutputSchema, capabilities: { request: true, listen: true, paginate: true } }) .addMutation("create", { inputSchema: createInputSchema, outputSchema: deploymentSchema, capabilities: { returnsItem: true, emitsEvents: true } }) .addEventSource("mutations", { type: "mutation", schema: mutationEventSchema, emitsCreated: true, emitsUpdated: true, emitsDeleted: true, config: { mutations: ["create", "update", "delete"], includePreviousState: true } }) .addEventSource("webhooks", { type: "external", schema: webhookEventSchema, emitsCreated: false, emitsUpdated: true, emitsDeleted: false, config: { system: "github", webhookPath: "/webhooks/github" } }) .build();
